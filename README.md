# Pharmacy Management System 💊

A web-based Pharmacy Management System developed using **Java, JSP, Servlets, JDBC, and MySQL**. The system helps manage medicines, categories, doctors, users, prescriptions, shopping carts, and customer orders through separate user and administrator functionalities.

## 📌 Project Overview

The Pharmacy Management System is designed to digitize common pharmacy operations and provide an easy-to-use platform for managing medicines and customer orders.

The application follows a structured Java web application architecture using **JSP, Servlets, JDBC, and MySQL**.

## 🚀 Features

### 👨‍💼 Admin Module

- Admin login and authentication
- Admin dashboard
- Add, update, view, and delete medicine categories
- Add and manage medicines
- View medicines in alphabetical order
- Add and manage doctors
- View customer orders
- Manage order status
- Verify prescription-based orders
- Secure logout and session management

### 👤 User Module

- User registration
- User login and authentication
- Browse available medicines
- Search/filter medicines
- View medicine details
- Add medicines to shopping cart
- Update cart quantity
- Remove items from cart
- Place orders
- View previous orders
- Online payment workflow
- Prescription-based ordering
- View doctors

### 💊 Medicine Management

- Medicine name and category management
- Medicine price management
- Stock management
- Medicine search and filtering
- Medicine update and deletion

### 🛒 Shopping & Orders

- Add medicines to cart
- Update cart items
- Remove cart items
- Place orders
- View order history
- Order status management
- Prescription verification
